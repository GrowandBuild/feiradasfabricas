# Highlights de Vídeos

Esta pasta contém os vídeos para a seção de destaques da página inicial.

## Layout:
- **Desktop**: 10 vídeos em grid (10% de largura cada)
- **Tablet/Mobile**: 3 vídeos por linha (33.33% de largura cada)

## Como substituir os vídeos:

1. **Formato recomendado**: MP4
2. **Aspect ratio**: 9:16 (vertical, como stories do Instagram)
3. **Duração**: 10-30 segundos
4. **Resolução**: 1080x1920 pixels ou similar

## Como atualizar:

1. Crie seus vídeos no formato especificado
2. Substitua os arquivos existentes nesta pasta
3. Mantenha os mesmos nomes de arquivo
4. Os vídeos serão automaticamente atualizados na página

## Dicas:

- Use vídeos curtos e impactantes
- Adicione texto sobreposto aos vídeos
- Mantenha o tema visual consistente
- Teste em diferentes dispositivos
